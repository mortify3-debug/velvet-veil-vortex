# Velvet Veil Vortex — Official Site

Киберпанк-стиль + твоя картинка в Hero.

## Структура
```
index.html
css/styles.css
js/script.js
assets/images/hero.png   ← твоя картинка
assets/music/            ← сюда клади MP3 (neon-blood.mp3)
```

## Как загрузить на GitHub
1. Распакуй архив
2. Создай репозиторий на GitHub
3. Загрузи **содержимое** папки (index.html, css, js, assets) — не саму папку
4. Подключи к Cloudflare Pages

## Редактирование
- Тексты, даты, email → index.html
- Картинка Hero уже стоит (assets/images/hero.png)
- MP3 → assets/music/neon-blood.mp3 + обнови src в <audio>
