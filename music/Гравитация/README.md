# Альбом «Гравитация»

Загружайте MP3-композиции этого альбома непосредственно в эту папку: `music/Гравитация/`.

После Commit + Push GitHub Actions автоматически обновит `albums.json` и `songs.json`. Треки получат обложку `assets/covers/gravitation.jpg` и будут работать со стандартными функциями сайта: воспроизведение, пауза, перемотка и скачивание.
