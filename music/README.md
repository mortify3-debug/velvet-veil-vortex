# Альбомы = папки

```
music/
  Киберпанк/          ← положите сюда MP3
  Город света/
  Рекурсия миров/
```

После добавления файлов:

```bash
node generate-songs.mjs
```

или просто Commit + Push (GitHub Actions соберёт каталог сам).

Обложки альбомов лежат в `assets/covers/`:
- cyberpunk.jpg → Киберпанк
- gorodsveta.jpg → Город света
- rekursia-mirov.jpg → Рекурсия миров
