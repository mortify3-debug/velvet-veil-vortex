# Velvet Veil Vortex — GitHub + Cloudflare

Статический музыкальный сайт без PHP и базы данных.

Сайт состоит из **двух обложек**:
1. Главный экран с названием, слоганом и кнопкой «Слушать»
2. Раздел музыки с альбомами и треками

Листается колёсиком мыши / свайпом (scroll-snap).

## Как добавить альбом и треки

Откройте файл **`albums.json`** и добавьте объект альбома:

```json
{
  "id": "my-album",
  "title": "Название альбома",
  "cover": "./assets/covers/MyAlbum.jpg",
  "year": "2026",
  "tracks": [
    {
      "title": "Название песни",
      "src": "./music/Song.mp3"
    },
    {
      "title": "Ещё одна песня",
      "src": "./music/Another.mp3"
    }
  ]
}
```

### Шаги

1. Положите MP3 в папку `music/`
2. Положите обложку альбома в `assets/covers/` (JPG / PNG / WEBP)
3. Добавьте запись в `albums.json` (см. пример выше)
4. Сделайте Commit и Push — сайт обновится

У каждого трека можно указать свою обложку полем `"cover"`. Если не указать — берётся обложка альбома.

## Структура файлов

- `index.html` — разметка
- `style.css` — стили (адаптив под мобильные)
- `app.js` — плеер и альбомы
- `albums.json` — **все альбомы и треки** (редактируйте этот файл)
- `assets/cover.png` — фоновая обложка первого экрана
- `assets/covers/` — обложки альбомов
- `music/` — MP3-файлы

> Старый `generate-songs.mjs` больше не обязателен — каталог задаётся вручную в `albums.json` для удобного группирования по альбомам.

## GitHub Pages

Можно использовать workflow из `.github/workflows/update-and-deploy.yml`.

## Мобильные устройства

Первая обложка занимает весь экран (`100dvh`), картинка с `object-fit: cover`.  
Кнопка «Слушать» переносит на второй экран и запускает первый трек.  
Плеер закреплён внизу с учётом safe-area на iPhone.
