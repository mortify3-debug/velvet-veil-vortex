# Velvet Veil Vortex

## Автозагрузка треков (быстрый пайплайн)

1. Положите **реальные** MP3 в папку альбома в репозитории.
2. `git add` → `git commit` → `git push` в `main`.
3. GitHub Actions / Cloudflare **сами** запускают `node generate-songs.mjs`, пересобирают `albums.json` + `songs.json` и деплоят сайт.

```
music/
  Киберпанк/
    новая-песня.mp3
  Город света/
  Рекурсия миров/
```

Только файлы с расширением `.mp3` / `.m4a` / `.ogg` / `.wav` попадают в каталог. Пустые аудиофайлы сорвут деплой (проверка в CI). Файлы без аудио-расширения не учитываются.

После push незавершённый деплой отменяется (`cancel-in-progress`), чтобы новая версия каталога выходила быстрее.

### Вручную локально

```bash
node generate-songs.mjs
```

### Новый альбом

1. Создайте `music/Название/`
2. Положите MP3
3. Обложку — в `assets/covers/` (имя файла ≈ название альбома)
4. Push (или `node generate-songs.mjs`)

## Cloudflare Pages

- Build command: `node generate-songs.mjs`
- Output directory: `/`

JSON (`albums.json`, `songs.json`) отдаётся с `Cache-Control: no-cache`, аудио — с долгим кэшем.

## Управление

- Кнопка ▶ перед названием трека: **play / pause**
- Регулятор громкости — справа в строке трека
- Нижний плеер на сайте **скрыт**; управление на экране блокировки смартфона (Media Session: play/pause, ← →, обложка в стиле сайта)
- Скролл списка треков без видимого тулбара
- **Десктоп:** колёсико между обложками — один шаг; **Ctrl + колёсико** — масштаб страницы (обложки не переключаются)
- **Мобильный:** свободная прокрутка обложек без snap и без анимированных переходов
- Слоган: «Громче чем музыка!»
